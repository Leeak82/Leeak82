## How I Build

Most of these projects started with a real problem I wanted to solve rather than a tutorial. I generally work from a usable MVP toward deeper architecture, then add testing, failure handling, deployment, and better UX as the project matures.

The repositories intentionally show that progression. Some are polished, some are experiments, and some are active works in progress. The point of this GitHub is to document what I have actually learned by building.
